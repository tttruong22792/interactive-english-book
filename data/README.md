# data/

Đây là thư mục nội dung học.

- `content-index.js`: metadata và đường dẫn lesson.
- `content-loader.js`: loader dùng chung.
- `english/`: nội dung English.
- `japanese/`: nội dung Japanese.
- `templates/`: mẫu để tạo bài mới.

Nếu bạn dùng Claude Code, hãy yêu cầu Claude đọc `CONTENT-SCHEMA.md` trước khi thêm lesson.
